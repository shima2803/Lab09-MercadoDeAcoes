# Lab 09 - Mercado de Ações

Projeto de análise e visualização de dados do mercado de ações desenvolvido no **Power BI**, com base no dataset `StockMarket.xlsx`.

## Objetivo

Construir um dashboard interativo capaz de apresentar, de forma clara e analítica, indicadores relevantes sobre o desempenho de ações ao longo do tempo, permitindo a tomada de decisão baseada em dados.

## Arquivos do Projeto

| Arquivo | Descrição |
|---------|-----------|
| `Lab 09 - Mercado de Ações.pbix` | Relatório do Power BI com o dashboard e modelagem de dados |
| `StockMarket.xlsx` | Base de dados utilizada como fonte do relatório |
| `dashboard.png` | Print do dashboard final |

## Dashboard

![Dashboard - Mercado de Ações](dashboard.png)

## Tecnologias Utilizadas

- **Power BI Desktop** — criação do relatório, modelagem e visualizações
- **Microsoft Excel** — fonte dos dados
- **DAX** — medidas e cálculos analíticos

## Como Visualizar

1. Faça o download do arquivo `Lab 09 - Mercado de Ações.pbix`
2. Abra-o no **Power BI Desktop**
3. Caso seja solicitado, aponte a fonte de dados para o arquivo `StockMarket.xlsx` presente no projeto
